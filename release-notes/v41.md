# KVSP v41

## Highlights

- Bundle Tangor as a KVSP submodule and select it directly with
  `kvsp ... --backend tangor`.
- Ship both Iyokan and Tangor evaluator binaries in the AVX-512 and AVX2
  release archives. Tangor uses the native cuFHEpp GPU evaluator when `-g` is
  specified.
- Update the release build environment to CUDA 13.3.1 on Ubuntu 24.04.

## Compatibility

Block Binary Keys and Subset Keys are now the default representation across
Iyokan, Tangor, and KVSP. Regenerate secret keys, bootstrapping/evaluation
keys, encrypted executables, and snapshots created with earlier defaults.
